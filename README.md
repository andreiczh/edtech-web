# Копилот — веб-прототип (голосовая практика)

Десктопный веб-интерфейс голосового ИИ-тренажёра. Пока это **UI-прототип**: интерфейс
и все состояния диалога работают, но ответы ИИ **замоканы таймерами** — реального звука/сети нет.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка прод-версии: `npm run build`, предпросмотр: `npm run preview`.

## Стек

React 19 + Vite 6 + TypeScript, стили — обычный CSS (`src/index.css`). Без бэкенда.

## Навигация

Сайдбар — 3 режима, у каждого свой оттенок фона (одна палитра, разный тон):

| Режим | Тема фона | Содержимое |
|---|---|---|
| **Разговор с носителем** | синий | голосовой экран (по умолчанию) |
| **Подготовка к ЕГЭ** | зелёный | 2 вкладки: **Тренажёр** (симуляция устного экзамена, см. `src/ege/`) + **Ответ в формате ЕГЭ** (заглушка) |
| **Подготовка к ОГЭ** | красный | заглушка `soon…` |

Тема задаётся через `data-theme` на `.app` (см. `src/App.tsx` → `THEME`, цвета в `src/index.css`).

## Структура

| Файл | Что делает |
|---|---|
| `src/App.tsx` | раскладка: сайдбар + вкладки + область контента |
| `src/types.ts` | типы `Mode` (ege/oge) и `EgeTab` (trainer/format) |
| `src/components/Sidebar.tsx` | боковое меню с режимами |
| `src/components/TrainerScreen.tsx` | голосовой экран: круги + подпись + кнопка |
| `src/components/Placeholder.tsx` | заглушка (`soon…` / «набросаем позже») |
| `src/useConversation.ts` | **машина состояний** диалога (idle → listening → processing → speaking). Здесь замоканы задержки |
| `src/components/VoiceOrbs.tsx` | 4 круга-индикатора |
| `src/components/MicButton.tsx` | кнопка-микрофон с состояниями |
| `src/index.css` | палитра из макета + все анимации (`@keyframes`) |

## Состояния и анимация кругов

- **idle** — покой, лёгкое «дыхание».
- **listening** (говорит юзер) — «эквалайзер»: круги дёргано растягиваются по вертикали.
- **processing** — синхронный пульс («думаю»).
- **speaking** (отвечает ИИ) — плавная «волна» со сдвигом по фазе.
