EdTech ИИ-копилот: голосовой тренажёр разговорного английского для **устного ЕГЭ**.

bootstrap. MVP: веб (десктоп), потом мобайл.

## Фронтенд (готов)
Стек: **React 19 + Vite 6 + TypeScript, обычный CSS** (без Tailwind). Дизайн — «Liquid Glass»
(матовое стекло), палитра из макета.
- **Каркас:** логотип сверху по центру; снизу — нижняя панель: горизонтальный зацикленный
  **слайдер режимов** (`ModeSlider`) по центру + **личный кабинет** слева (`Profile`, аватар+ник → ЛК/Настройки-модалка). Сайдбара нет.
- **3 режима** (каждый со своим оттенком фона): **Разговор с носителем** (синий, свободная
  голосовая практика — круги+микрофон), **Подготовка к ЕГЭ** (зелёный), **Подготовка к ОГЭ** (красный, `soon`).
- **ЕГЭ, 2 вкладки:**
  - **Тренажёр** — адаптивная тренировка: «Заполнить вакуум» (белая hero-кнопка), «Нарешать по
    типам заданий» (4 в ряд), «Работа над ошибками» (список с раскрытием) → `DrillSession` (5 заданий → фидбэк ИИ). Всё структура+плейсхолдеры.
  - **Ответ в формате ЕГЭ** — выбор варианта (`VariantPicker`, отметки «пройдено») → симуляция
    станции устного экзамена (`EgeTrainer`: регистрация→инструкция→мелодия→4 задания с таймерами и записью) → **экран результата** (`ExamResults`: ИИ-саммари + таблица баллов + разбор ошибок по критериям).
- **Анимация кругов:** я говорю → прыгающие «точки»; ИИ говорит → вертикальное растяжение (эквалайзер).
- **Ключевые файлы:** `src/App.tsx`, `src/ege/*` (examFlow, EgeTrainer, ExamKit, ExamResults, VariantPicker, EgeFormat, TrainerHub, DrillSession, trainerData), `src/components/*` (ModeSlider, Profile, Logo, TrainerScreen, VoiceOrbs, MicButton), `src/index.css`.
- **Важно по раскладке:** `.main` обязан иметь `min-height:0`, иначе футер (нижняя панель) выталкивается за экран. Требование: нижняя панель видна ВСЕГДА.

## Бэкенд (скелет — Этап 1, спайк)
Папка `backend/`. Собран минимальный «спайк голосовой петли»: `микрофон → STT → LLM → TTS → звук`, push-to-talk, non-streaming.
- `main.py` — FastAPI: `POST /talk` (STT→LLM→TTS+замер задержки), `GET /health`, отдаёт `test.html` на `/`. Клиенты создаются лениво (сервер стартует и без ключей).
- `test.html` — страница записи микрофона (открывать через `http://localhost:8000/`, не файлом — микрофон только на localhost/https).
- `requirements.txt`, `.env.example`, `run.ps1` (Windows: `git pull`+install+run одной командой), `DEPLOY-2-machines.md`, `README.md`.
- **Проверено на Маке:** сервер поднимается, `/` отдаёт страницу (HTTP 200). Окружение уже
  создано в `backend/.venv` на Маке (Python 3.9). Что осталось: вписать ключи в `.env` и прогнать петлю.

## Стек бэкенда (решение) — «API-путь», GPU не нужна
(Windows-ноут с встроенной слабой видеокартой → self-host моделей отпадает.)
- **STT:** Groq Whisper (free tier, OpenAI-совместимый).
- **LLM:** Gemini 2.5 Flash-Lite / DeepSeek V4 Flash **через provod.ai** (оплата из РФ рублями).
- **TTS:** сейчас Windows/mac SAPI (`pyttsx3`, для спайка) → на Этапе 2 **Kokoro-82M** (CPU, англ., бесплатно) или API-TTS. Русский голос не нужен — тьютор говорит по-английски.
- **Оркестратор:** Этап 2 — **Pipecat** (стриминг STT→LLM→TTS + Silero VAD + barge-in). Цель латентности 1.5–3с.
- Бюджет пилота ~$20–35/мес; спайк ≈ $0.

## Конструкция «две машины»
- **Mac = разработка** (Claude Code тут, git push). **Windows-ноут = сервер** (git pull → uvicorn, РФ).
- Связь: **Git/GitHub** (код), `.env` руками на сервере (не в git), тест — на самом Windows
  (`localhost:8000`) или с Мака через **HTTPS-туннель** (Tailscale/cloudflared, т.к. микрофону нужен https).
- **Claude нужен только на Маке.** Windows-серверу он не требуется (там чистый Python). AI (provod.ai/Groq) зовёт сам Windows-сервер из РФ — это правильно.

## Ограничения / грабли
- OpenAI из РФ недоступен → LLM только через агрегатор (provod.ai). OpenRouter закрыл РФ.
- Микрофон в браузере — только на **https или localhost** (secure context).
- Для пилота: HTTPS обязателен (Caddy авто-TLS), auth не строить — коды доступа.
- SpeechKit STT (10 ₽/мин) — не использовать, съест бюджет. Groq/self-host.
