# Приёмочный тест перед запуском

Сам тест — интерактивная страница, она раздаётся вместе с приложением:

**https://pingo-ai-dpd9.onrender.com/manual-test.html**

Открывать с телефона, проходить как настоящий ученик. Отметки и заметки
сохраняются в браузере (можно закрыть и вернуться), в конце кнопка «Собрать
отчёт» выдаёт текст только с проблемами — его и присылать агенту.

Исходник страницы: `public/manual-test.html`. Лежит именно там, а не в docs:
две копии одного файла неизбежно разъезжаются, а раздавать надо ту, что
собирается вместе с фронтом.

Что проверяется, по этапам:

1. регистрация по коду доступа (включая согласие на хранение записей);
2. главный экран — помещается ли всё без прокрутки;
3. меню заданий — №39 закрыт «coming soon», у 40 видна фотография;
4. задание 40 — вопросы, разбор, цитаты из своей речи, жалоба;
5. задание 41 — вопросы звучат голосом;
6. задание 42 — монолог, балл, оговорка о точности;
7. разговор с ИИ — ответ голосом, память беседы, разбор;
8. кабинет — настройки, согласие, выход и повторный вход;
9. то, что ломается чаще всего: «назад» на середине, блокировка экрана,
   тишина вместо ответа, медленный интернет.
