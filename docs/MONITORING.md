# Мониторинг: как узнать о падении раньше учеников

Две независимые половины. Обе бесплатные, обе настраиваются один раз.

## 1. Внешний пингер (обязательно — сам себя мёртвый сервер не разбудит)

UptimeRobot, бесплатный тариф (50 мониторов, проверка раз в 5 минут).

1. Зарегистрируйся на https://uptimerobot.com (почта + пароль).
2. **Add New Monitor**:
   - Monitor Type: `HTTP(s)`
   - Friendly Name: `Pingo AI`
   - URL: `https://pingo-ai-dpd9.onrender.com/health`
   - Monitoring Interval: `5 minutes`
3. В **Alert Contacts** добавь свою почту (или их Telegram-интеграцию).

Готово: письмо при падении и при восстановлении. Бонус: пинги раз в 5 минут
не дают Render заснуть днём — наш самопинг остаётся страховкой.

## 2. Алерты из самого сервера (Telegram)

Сервер шлёт владельцу СОБЫТИЯ (не поток логов):
- рестарт процесса (= деплой или падение с подъёмом);
- бюджет LLM перешёл в eco / low / empty;
- 5 сбоев STT или LLM за 10 минут (единичные обрывы не алертят);
- edge-tts деградировал на запасной Mistral (пропали голоса персон).

Одна тема — не чаще раза в 30 минут, шторма не будет.

### Настройка (5 минут)

1. В Telegram найди **@BotFather** → `/newbot` → имя и username бота.
   BotFather выдаст **токен** вида `1234567:AA...` — никому не показывай.
2. Напиши своему боту любое сообщение (иначе он не сможет писать первым).
3. Открой в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найди в ответе `"chat":{"id":123456789` — это твой **chat_id**.
4. В панели Render → Environment добавь:
   - `TELEGRAM_BOT_TOKEN` = токен из шага 1
   - `TELEGRAM_CHAT_ID` = число из шага 3
5. Manual Deploy → после старта придёт первое сообщение
   «Сервер запустился» — это и есть проверка, что канал работает.

Без этих переменных сервер просто молчит — ничего не ломается.
