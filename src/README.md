# src — фронтенд (React 19 + Vite + TypeScript)

| Папка | Что внутри |
|---|---|
| `mini/` | оболочка телефона и мини-приложения MAX |
| `screens/` | экраны настольной версии |
| `ege2/` | задания, запись, отправка на разбор, споры, избранное |
| `talk/` | разбор беседы |
| `auth/` | вход, регистрация, вход через MAX |
| `account/` | кабинет: настройки и статистика |
| `max/` | мост к MAX Bridge |
| `components/` | общие компоненты |
| `design/` | стили и дизайн-система |

В корне: `main.tsx` (точка входа), `App.tsx` (маршрутизация и каркас),
`useConversation.ts` (разговор: запись, поток ответа, проигрывание),
`backendError.ts` (тексты сетевых ошибок).

Правила работы с фронтом — [`CLAUDE.md`](CLAUDE.md).
