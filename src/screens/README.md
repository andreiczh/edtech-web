# src/screens — экраны настольной версии

- `HomeScreen.tsx`, `CalendarScreen.tsx`, `StatsScreen.tsx`, `ProfileScreen.tsx` —
  главная, календарь, статистика, кабинет.
- `AuthScreens.tsx` — вход, регистрация, вход через MAX.
- `EgeMenuScreen.tsx`, `SessionScreen.tsx`, `TaskScreen.tsx`, `ResultView.tsx` —
  выбор задания, серия вариантов, прохождение, разбор.
- `ConversationScreen.tsx` — разговор с собеседником.
- `AdminScreen.tsx` — админка.

`homeV2Layout.ts` сгенерирован конвейером `tools/home-layout`, руками его не правят.
