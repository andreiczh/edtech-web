# src/ — фронтенд

React 19 + Vite 6 + TypeScript, **обычный CSS** (`index.css`). Tailwind осознанно не берём.
Дизайн-система — **Liquid Glass** (матовое стекло: `backdrop-blur` + `saturate`).

## Каркас
Логотип сверху → `main` во всю ширину → нижняя панель: слайдер режимов (`ModeSlider`) +
личный кабинет (`Profile`). Три режима: «Разговор с носителем» (синий), «Подготовка к ЕГЭ»
(зелёный), «Подготовка к ОГЭ» (красный, `soon`).

## Грабли раскладки (наступали, не повторять)
- `.main` **обязан** иметь `min-height: 0` — иначе `flex: 1` не сжимается под контент
  и нижняя панель выталкивается за экран.
- Нижняя панель (ЛК + слайдер) видна **ВСЕГДА**, ничто её не перекрывает.
- Модалка личного кабинета рендерится через `createPortal` в `document.body` — иначе
  `backdrop-filter` на панели делает её контейнером для `position: fixed` и модалка проваливается.
- Рамка экзамена `.exam__frame` — flex-stretch + `min-height: 0` + внутренний скролл тела,
  НЕ фиксированная высота.

## Обращение к бэкенду
Только **относительные** пути: `/talk_stream`, `/monologue`, `/health`. Дефолт `BACKEND` —
пустая строка (same-origin), потому что бэкенд сам раздаёт собранный фронт. В dev
(`npm run dev`, :5173) проксируется на :8000 через `vite.config.ts`. Override — `VITE_BACKEND_URL`.

## MAX и запись с микрофона (15.09.2026)
- `max/bridge.ts` — признак запуска из MAX (фрагмент `#WebAppData=` → флаг
  в sessionStorage) и ленивая загрузка MAX Bridge. В обычном браузере
  библиотека MAX не грузится вовсе.
- Маршрут `maxlogin` (`MaxLoginScreen` в `AuthScreens.tsx`): вход сам, при
  ошибке — повтор и запасной вход по нику. Новому MAX-аккаунту согласие на
  корпус выставляется в «нет»: экрана согласия в MAX нет.
- Запись: MediaRecorder создаётся ТОЛЬКО через `ege2/audioMime.ts`
  (`makeRecorder`), blob подписывается `recordedType`, имя файла —
  `audioFileName`. iPhone пишет mp4, а не webm; новые места записи — только
  через эти три функции. Подробности — `docs/DECISIONS.md` §6.37.

## Мини-приложение — телефон и MAX (22.09.2026)
`src/mini/*`, стили `mini/mini.css`. Включается `useMobileShell` (MAX или
окно ≤ 820 px) — `App.tsx` тогда рисует `MiniApp` вместо каркаса с рейлом.
Все размеры — пункты макета × `--u`; ничего «на глаз» не двигать: макет —
источник правды, расхождение мерится сверкой по пикселям (§6.39). Иконки —
`mini/icons.ts` (генерируется, руками не править). Поток задания —
`Practice.tsx` (сейчас только №39), разбор — `ResultScreen.tsx`. Разделы без
макетов (календарь, статистика, кабинет, разговор, демо) — старые экраны в
`.mini-legacy`. Просмотр разбора без микрофона: `/#mini-result` + пример в
`sessionStorage['gospeak.mini.demo']`.
