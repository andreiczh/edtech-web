# src/mini — оболочка телефона и мини-приложения MAX

- `MiniApp.tsx` — корень оболочки и вкладки; `useMobileShell.ts` решает, когда
  её показывать.
- `MiniHome.tsx`, `MiniTalk.tsx`, `MiniStats.tsx`, `MiniSettings.tsx`,
  `MiniProfile.tsx` — главная, разговор, статистика, настройки, кабинет.
- `TaskPicker.tsx`, `Practice.tsx` — выбор задания и его прохождение.
- `ResultScreen.tsx`, `ResultScreen40.tsx`, `ResultScreen42.tsx`, `ResultBits.tsx`,
  `ResultExtras.tsx` — экраны разбора.
- `audioPeaks.ts`, `calendar.ts`, `mistakes.ts`, `icons.ts`, `Ambient.tsx` — волна
  записи, календарь занятий, «вариант по ошибкам», иконки, фон.
- `mini.css` — стили оболочки.
