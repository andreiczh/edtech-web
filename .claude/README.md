# .claude — настройки Claude Code

Служебная папка среды разработки. К продукту не относится и в Docker-образ не
попадает (исключена в `.dockerignore`).

- `launch.json` — как поднять фронт (`npm run dev`, порт 5173) и бэкенд
  (uvicorn, порт 8000) для предпросмотра.
- `settings.json` — разрешения на команды для агента.

Правила работы агента с проектом — в [`../CLAUDE.md`](../CLAUDE.md).
