## Одна машина (решение от 22.07.2026)

**Всё живёт на Windows-ноуте в РФ:** `C:\Users\Lenovo\edtech-copilot-web`. Здесь и код,
и сервер, и тестирование. **Мак из работы выведен — проект там не трогаем.**

Раньше была схема «код пишет Мак, Windows только запускает», со связью через git и
правилом эстафеты. Она отменена: пересылка через git на каждую правку стоила дороже,
чем экономила, а главное — код писался там, где его нельзя было прогнать вживую.
Именно так две «готовые» фичи (`/talk_stream`, `/monologue`) оказались мёртвыми,
см. `docs/DECISIONS.md` §5, пункты 7–8.

### Правила git (одна машина)
1. **Ветка `main`, без feature-веток.** GitHub теперь — резервная копия и история,
   а не канал связи между машинами.
2. **`git pull --rebase` в начале сессии.** Расхождение маловероятно, но `run.ps1`
   всё равно делает `git pull` при старте — пусть дерево будет чистым.
3. **Коммит и push сразу после правки**, не «потом»: `run.ps1` начинается с `git pull`,
   и незакоммиченные правки могут сломать запуск сервера.
4. Правки в `HANDOFF.md`, `CLAUDE.md` и `docs/DECISIONS.md` теперь делает агент здесь —
   ограничение «только Мак» снято вместе со второй машиной.
5. Без явного «да» от пользователя **НИКОГДА**: `git push --force`, `git reset --hard`,
   `git checkout -- .`, `git clean -fd`, `git rebase` (кроме `--abort`).

### Обязательное следствие: фичу проверяем живым запросом
Раз код пишется на той же машине, где крутится сервер, — **«собралось» больше не считается
за «работает»**. Каждый новый эндпоинт и каждая правка промпта прогоняются реальным
запросом с замером до того, как назвать их готовыми. Микрофон для этого не нужен:
речь синтезируется через `edge-tts` и шлётся в эндпоинт ровно как из браузера.

**Стоп-лист провайдеров — проверено практикой, не статьями:**
- ❌ **Groq / OpenAI / Gemini / xAI** — экспортный контроль США, из РФ заблокированы.
- ❌ **OpenRouter** — Cloudflare-блок РФ: «Sorry, you are blocked» даже в браузере.
- ❌ **DeepSeek** — API доступен, но бесплатный грант не начисляется (`402 Insufficient Balance`).
- ❌ **Yandex SpeechKit STT** — 10 ₽/мин, съедает весь бюджет.
- ✅ **Mistral, edge-tts, HuggingFace** (веса whisper) — работают из РФ без VPN.

Не предлагать провайдеров из стоп-листа. Не верить веб-статьям о доступности из РФ —
только прямой проверке в браузере на машине пользователя.

## Правила работы

- **Пользователь не сильно технический.** Команды давать готовыми блоками целиком,
  включая `cd`. Новое окно PowerShell открывается в `C:\Users\Lenovo`, а не в проекте.
- **`.ps1` — только ASCII.** Windows PowerShell 5.1 читает их как CP1251;
  кириллица и длинные тире ломают парсер.
- **После правки фронта на Windows:** `npm.cmd run build` **и перезапуск бэкенда**.
  Бэкенд решает, раздавать ли `dist/`, один раз при старте — без перезапуска увидишь старое.
- **`npm install` НЕ запускать** — он переписывает `package-lock.json` (выкидывает
  macOS-бинарники rollup/esbuild, записанные Маком) и после этого `git pull` падает с
  `unstaged changes`. Ставить зависимости только через **`npm.cmd ci`**.
  *(Когда лок-файл будет пересобран на Windows начисто, это правило можно снять —
  оно наследство двухмашинной схемы.)*
- **Секреты.** `.env` не коммитить никогда. Ключ не просить прислать в чат и не печатать
  в выводе команд. Единственная копия ключа Mistral живёт на Windows-ноуте.
- **Стиль.** Критический партнёр, не поддакивать. Помечать `[Факт]` / `[Допущение]` /
  `[Мнение]`, в конце — уверенность в %. Кратко и прямо, по-русски.
