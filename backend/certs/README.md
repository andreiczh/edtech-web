# backend/certs — недостающее звено цепочки сертификатов

`globalsign-gcc-r3-dv-tls-2020.pem` — промежуточный сертификат GlobalSign.
Сервер открытого банка ФИПИ не досылает его в цепочке, и Python без него
падает с «unable to get local issuer». `fipi_import.py` подклеивает этот файл
к обычному набору корневых сертификатов. Проверку TLS при этом не отключаем.

Файл публичный, секретов в папке нет.
