# Две машины: Mac (разработка) + Windows-ноут (сервер)

Мак — где пишется код. Windows-ноут в РФ — где всё запускается и тестируется.
Связывает их **только Git**, ветка `main`.

---

## Что едет между машинами, а что нет

| Что | Через git? | Комментарий |
|---|---|---|
| Исходники, конфиги, документация | ✅ да | обычный `git pull` |
| `CLAUDE.md`, `.claude/settings.json` | ✅ да | контекст для AI-агента едет вместе с кодом |
| Собранный фронт `dist/` | ❌ нет | **после каждого pull делать `npm.cmd run build`** |
| `node_modules/` | ❌ нет | `npm.cmd install` |
| `backend/.venv/` | ❌ нет | маковский venv на Windows бинарно несовместим |
| `backend/.env` (ключ Mistral) | ❌ **и не должен** | единственная копия живёт на Windows |
| Кеш модели whisper (~150 МБ) | ❌ нет | качается сам при первом старте |
| История чатов и «память» Claude | ❌ нет | у каждой машины своя, это нормально |

**Ключевое следствие:** контекст для AI-агента переносится не «синхронизацией Claude»,
а тем, что он лежит в репозитории — `CLAUDE.md`, `HANDOFF.md`, `docs/DECISIONS.md`.
Новый агент на новой машине читает их и входит в курс дела.

## Разовая настройка Windows

```powershell
cd C:\Users\Lenovo\edtech-copilot-web
git config --global pull.rebase true
git config --global core.autocrlf true
```

`pull.rebase true` — обычный `git pull` не плодит мусорные merge-коммиты.
`core.autocrlf true` — Windows-редакторы не переписывают переводы строк целиком.
**То же `pull.rebase true` выполнить и на Маке.**

Если `git pull` просит логин (репозиторий приватный):

```powershell
winget install --id GitHub.cli -e
```

Затем **закрыть окно PowerShell и открыть новое**, иначе `gh` не найдётся:

```powershell
gh auth login
```

Отвечать: `GitHub.com` → `HTTPS` → «Authenticate Git with your GitHub credentials?» → **Y**
→ `Login with a web browser` → код вида `XXXX-XXXX` вставить в браузере → Authorize.

## Ежедневный цикл

**Сначала Ctrl+C** в окне, где крутится сервер — запущенный uvicorn держит файлы,
и `git pull` с `npm run build` упадут.

```powershell
cd C:\Users\Lenovo\edtech-copilot-web
git pull --rebase
npm.cmd install
npm.cmd run build
cd backend
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Или одной командой вместо всего блока: `powershell -ExecutionPolicy Bypass -File backend\run.ps1`

Проверить, что сборка реально прошла: в выводе должна быть строка `built in …`.
Если TypeScript ругнулся — сборки **не было**, `dist/` остался старый, дальше не идти.

После пересборки в браузере жать **Ctrl+F5** (жёсткая перезагрузка) — имена файлов сборки
меняются, и закешированный старый `index.html` даёт белый экран.

## Как тестировать

**На самом Windows** — открыть `http://localhost:8000/`. Микрофон работает,
потому что `localhost` это secure context. Ничего настраивать не нужно. Это основной способ.

**С Мака** — микрофон в браузере доступен только на `https` или `localhost`, поэтому
по `http://<ip-windows>:8000` он НЕ включится. Нужен HTTPS-туннель, а с туннелями из РФ
всё плохо: `trycloudflare` флапает, `ngrok` заблокирован. Не допробован Tailscale
(`tailscale serve 8000`) — если понадобится, начинать с него.

**Вывод:** тестируем на самом Windows-ноуте. Публичная ссылка — отдельная задача
(RU-VPS + домен + HTTPS + коды доступа), не туннель с ноутбука.

## Правила против конфликтов

1. **Эстафета, не параллель.** Один закончил и запушил → только тогда второй делает pull.
2. **Код пишет Мак.** Windows правит только окружение, `.env`, запуск.
3. **`git pull --rebase` до первой строчки работы** — на обеих машинах.
4. **Коммит сразу после правки.** `run.ps1` начинается с `git pull`, и незакоммиченные
   правки на Windows не просто теряются — они ломают запуск сервера.
5. **`HANDOFF.md` и `CLAUDE.md` редактирует только Мак.** Первый кандидат на конфликт.
6. **Только ветка `main`.**
7. **Секреты — только в `backend\.env` на Windows.** Никогда в git, никогда в чат.
   Ключ в истории git публикуется навсегда, даже после удаления файла.

### Если что-то пошло не так

```powershell
# Незакоммиченные правки мешают pull — отложить, обновиться, вернуть:
cd C:\Users\Lenovo\edtech-copilot-web
git stash
git pull --rebase
git stash pop

# Ветки разошлись, push отклонён:
git pull --rebase
git push

# Застряли в rebase (в приглашении REBASE, красное CONFLICT) — откатиться назад:
git rebase --abort
```

После `git stash pop` с конфликтом правки **не потеряны** — они в `git stash list`.

**Никогда без явного согласия:** `git push --force`, `git reset --hard`,
`git checkout -- .`, `git clean -fd`. Они уничтожают несохранённое молча и без корзины.

## Обмен рантайм-данными

Логи сессий (когда появятся, SQLite) будут жить **на Windows-сервере** — там же,
где крутится приложение. Смотреть с Мака: через дашборд-эндпоинт или копированием файла.
`.env` через git не синхронизировать никогда.
