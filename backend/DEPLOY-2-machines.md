# Две машины: Mac (разработка) + Windows-ноут (сервер)

Мак — где ты пишешь код (с Claude). Windows-ноут — где всё запускается и тестируется
(в РФ, Claude ему не нужен). Связывает их Git.

## Разовая настройка Windows-сервера

1. Установить **Git** (git-scm.com) и **Python 3.11** (`winget install Python.Python.3.11`).
2. Склонировать репозиторий:
   ```powershell
   git clone https://github.com/andreiczh/edtech-copilot-web.git
   cd edtech-copilot-web\backend
   ```
3. Запустить: `powershell -ExecutionPolicy Bypass -File run.ps1`
   - Первый раз он создаст `.env` и откроет блокнот — впиши ключи (Groq, provod.ai), сохрани, запусти снова.

## Ежедневный цикл

1. **На Маке** правишь код (со мной) → `git push`.
2. **На Windows** обновляешь и запускаешь: `.\run.ps1` (внутри `git pull` + установка + uvicorn).
3. **Тестируешь** (см. ниже).

## Как тестировать

### Вариант 1 — на самом Windows (проще всего)
Открой в браузере Windows **http://localhost:8000/**. Микрофон работает (localhost —
безопасный контекст). Ничего настраивать не нужно.

### Вариант 2 — смотреть/тестировать с Мака
Микрофон в браузере доступен только на **https** или **localhost**. С Мака по
`http://<ip-windows>:8000` микрофон НЕ включится. Нужен HTTPS-туннель к серверу:

**Tailscale (рекомендую — приватно, стабильно, работает между сетями):**
- Установить Tailscale на Мак и Windows, войти в один аккаунт.
- На Windows: `tailscale serve 8000`
- На Маке открыть выданный адрес вида `https://<имя-windows>.<tailnet>.ts.net` → микрофон работает.

**cloudflared (быстро, без аккаунта, но URL временный и публичный):**
- На Windows: `cloudflared tunnel --url http://localhost:8000`
- Скопировать выданный `https://xxxxx.trycloudflare.com`, открыть на Маке.

Если один из туннелей из РФ капризничает — попробуй другой.

## Обмен данными (логи сессий и т.п.)
- Рантайм-данные (SQLite с логами сессий) живут **на Windows-сервере**.
- Посмотреть с Мака: либо через дашборд-эндпоинт (сделаем на этапе 3), либо
  скопировать файл через туннель (`scp` / общая папка).
- Секреты (`.env`) синхронизировать через git НЕЛЬЗЯ — держи их только на сервере.

## Важно про РФ
- **Claude** — только на Маке. Windows-серверу он не нужен (там чистый Python).
- **AI-сервисы** (provod.ai для LLM, Groq для STT) зовёт сам Windows-сервер из РФ —
  provod.ai для этого и предназначен (оплата рублями, без VPN).
